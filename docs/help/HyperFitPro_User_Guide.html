HyperFitPro Studio - User Guide

This offline guide explains the first public release of HyperFitPro Studio.

Workflow

  1. Select a working directory.
  2. Choose a hyperelastic model.
  3. Import one or more test data files.
  4. Run the recommended adaptive-bounds optimizer or choose another method.
  5. Review plots, iteration tables and model parameters.
  6. Generate PDF report, Excel calculator and FEA export bundle.
  7. Save the project as .hyp2fit.

Worked examples

  1. Neo-Hookean quick calibration with uniaxial and biaxial data.
  2. Mooney-Rivlin multi-mode fit using uniaxial, biaxial and planar data.
  3. Yeoh workflow starting from force-displacement data.
  4. Ogden high-strain global optimization.
  5. Gent / Van der Waals finite-extensibility fit with FEA export verification.

Plugin Workbench

Tool plugins are grouped by category. They can run on the current workspace or on imported .hyp2fit projects. Outputs are visible in the Plugin Results page.

Languages

The GUI supports Turkish, English, German, French and Spanish from the language selector in the header.

GitHub-ready structure

Root folder contains the launcher, README, license, requirements and project metadata. Verification tools are available from Diagnostics Center inside the GUI.
